# 카카오톡 이모티콘 메이커

AI를 활용하여 카카오톡 이모티콘을 자동으로 생성하는 React Native 앱입니다.

## 주요 기능

- **프롬프트 기반 생성**: 간단한 텍스트 프롬프트로 이모티콘 자동 생성
- **5가지 이모티콘 타입 지원**:
  - 멈춰있는 이모티콘 (32개, PNG)
  - 움직이는 이모티콘 (24개, WEBP 3개 이상 + PNG)
  - 큰 이모티콘 (16개, WEBP 3개 이상 + PNG)
  - 멈춰있는 미니 이모티콘 (42개, PNG)
  - 움직이는 미니 이모티콘 (35개, WEBP 3개 이상 + PNG)
- **크로스 플랫폼**: iOS와 Android 모두 지원
- **실시간 생성 진행 상황 표시**
- **이미지 다운로드 및 공유 기능**

## 기술 스택

- **React Native**: 크로스 플랫폼 모바일 앱 개발
- **TypeScript**: 타입 안정성
- **React Navigation**: 네비게이션
- **Google Gemini Imagen**: AI 이미지 생성
- **React Native FS**: 파일 시스템 관리

## 사용 방법

1. **프롬프트 입력**: 앱을 실행하고 원하는 이모티콘에 대한 설명을 입력하세요.
   - 예: "귀여운 곰 캐릭터가 다양한 표정을 짓는 모습"
   
2. **캐릭터 설명 (선택사항)**: 캐릭터의 외형을 더 자세히 설명할 수 있습니다.
   - 예: "밝은 갈색 곰, 작은 눈, 둥근 얼굴"

3. **이모티콘 타입 선택**: 생성할 이모티콘 타입을 선택하세요.

4. **생성 시작**: "이모티콘 생성하기" 버튼을 누르면 AI가 이모티콘을 생성합니다.

5. **결과 확인 및 다운로드**: 생성이 완료되면 결과를 확인하고 다운로드할 수 있습니다.

## 카카오톡 이모티콘 가이드라인

이 앱은 카카오톡 이모티콘 제작 가이드라인을 준수합니다:

- **멈춰있는 이모티콘**: 360x360px, PNG 형식, 32개
- **움직이는 이모티콘**: 360x360px, WEBP 3개 이상 + PNG, 총 24개
- **큰 이모티콘**: 720x720px, WEBP 3개 이상 + PNG, 총 16개
- **멈춰있는 미니 이모티콘**: 120x120px, PNG 형식, 42개
- **움직이는 미니 이모티콘**: 120x120px, WEBP 3개 이상 + PNG, 총 35개

## 추가 개발 필요 사항

다음 기능들은 추가 개발이 필요합니다:

1. **이미지 리사이즈 및 포맷 변환**: 
   - `react-native-image-resizer` 또는 네이티브 모듈 필요
   - PNG ↔ WEBP 변환 기능

2. **애니메이션 생성**: 
   - 움직이는 이모티콘의 경우 프레임 애니메이션 생성 로직 필요

3. **API 키 관리**: 
   - 안전한 API 키 저장 및 관리 시스템

4. **이미지 최적화**: 
   - 파일 크기 최적화
   - 품질 조정

5. **배치 다운로드**: 
   - ZIP 파일로 압축하여 다운로드

6. **이모티콘 미리보기**: 
   - 생성된 이모티콘 미리보기 기능
